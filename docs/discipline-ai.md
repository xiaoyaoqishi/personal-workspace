# AI 总结

入口 `/discipline/ai`，API `/api/discipline/ai/*`。提供日复盘、完整自然周复盘、生成重点（综合／计划执行／用机习惯）、精简／详细、事实依据抽屉、历史版本、重新生成、复制和 Markdown 下载。日期与报告版本保存在 URL，可刷新与前后退。

## 数据与统计

统计沿用每日计划和屏幕统计的既有规则；AI 不评分、不修改计划，不回写历史。后端先计算计划达成率、参与／已评价时段、设备累计与合并时长、夜间使用、应用排行、每日期间汇总及计划时段内的前台累计。应用占比以设备累计为分母，不能与合并时长混算。只接受已经结束的日期／自然周。

每份报告保留生成时的事实快照和稳定指纹。新事件、应用名称／分类、计划自评或已授权的备注改变时，旧报告标记待更新；显示旧报告时，数字和依据仍来自旧快照。导入时间改变但事实不变，不重复标记新数据。查看报告／GET 不调用模型、不产生费用；相同数据、偏好、模型和提示版本复用成功报告，显式重新生成才新增版本。失败保留上一份成功报告。

缺记录不推断为零使用，未评价不当作实际执行失败；周末／节假日不纳入计划达成率。前台记录不代表应用内活动、专注、分心、睡眠或拿起次数。历史计划已锁定，建议只能面向今天及未来。模型生成的结论仍需用户判断，依据 ID 和 JSON 格式经过程序校验，不代表语义可被完全自动证明。

## DeepSeek 接入

复用现有 `httpx` 和标准库，无新增依赖。官方接口固定为 `https://api.deepseek.com/chat/completions`；默认 `deepseek-flash`，关闭思考模式，使用 JSON 输出，输出上限为精简1800／详细3000 tokens。HTTP 禁止重定向，连接超时10秒、读取超时75秒，临时网络／限流／服务故障最多尝试两次；凭证和余额错误不重试。不记录密钥、请求正文或模型原始错误响应。

```bash
# 隐藏输入密钥，写到已忽略的 backend/data/discipline-ai.json，文件0600。
python3 scripts/configure_discipline_ai.py
# 可选指定服务端保存位置或模型名称
python3 scripts/configure_discipline_ai.py --output /受保护目录/discipline-ai.json --model deepseek-flash
```

服务读取 `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` 环境变量，或 `core.config.settings.data_dir/discipline-ai.json`。部署时将本机配置经已授权的 SSH 标准输入写入服务器对应数据目录，禁止把密钥放在参数、Git、前端、聊天回复或日志中。密钥不随代码部署生成或覆盖。生产依旧使用 `.codex/local/aliyun-prod.sh deploy`；现有 `/discipline/` nginx 回退支持 `/discipline/ai`，无需新增 nginx 或 systemd 服务。

仅发送当前账号的聚合统计、应用名称、计划主题、自评及抽取的证据；不发送用户名、设备 UUID、原始 Biome、其他模块数据、窗口正文。默认不发送计划文字备注；用户在复盘设置中明确开启后，每个选中时段最多发送240字。每日最多选取8个具体时段，其余仍纳入汇总。提示把所有资料当作数据，禁止遵循资料内的指令。

## 生成与自动化

报告任务持久化，后台线程原子领取任务；同一账号最多一个未完成任务，最多每日20次新生成。模型调用在数据库事务外，领取与写回前均校验账户仍可写。运行任务带4分钟租约，进程中断后过期任务变为可重试的失败状态，排队任务仍可继续处理。业务全部位于 `backend/services/discipline_ai/`，不新增 runtime 领域函数。

自动生成按账号显式开启，默认关闭，沿用用户保存的重点与长度。北京时间08:00后，当天发生屏幕事件导入且导入已稳定90秒，生成昨日复盘；周一再生成上一完整自然周。每个账号每种周期每天最多一个自动任务，后来补入数据只提示待更新，由用户选择是否重新生成。没有当日新导入时等待数据，无法把“无新事件”判断为采集已完成。后台每5秒处理队列、每分钟检查自动任务；不依赖某个浏览器保持打开。
